# 03 - 仓位与止损

这是A股优化版中最关键的部分。因T+1和涨跌停限制，必须比美股更保守。

## 风险参数建议

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 单笔风险比例 | 0.3% ~ 0.8% | 新手建议从0.3%-0.5%起步 |
| 单笔止损幅度 | 3% ~ 6% | 超过7-8%的形态直接放弃或大幅减小仓位 |
| 总仓位上限 | 初期30-50% | 趋势明确后可逐步提高，但绝不单票过重 |

## 仓位计算公式

```
单笔最大可亏损金额 = 总资金 × 风险比例
可买金额 = 单笔最大可亏损金额 ÷ 止损幅度
可买股数 = 可买金额 ÷ 进场价格（向下取整到100股）
```

### 计算示例

- 总资金：1,000,000 元
- 风险比例：0.5% → 单笔可亏 5,000 元
- 进场价：20 元
- 止损价：19 元 → 止损幅度 5%
- 可买金额 = 5,000 ÷ 0.05 = 100,000 元
- 可买股数 ≈ 5,000 股

## 止损位置原则

1. 优先放在「形态失效点」下方（VCP最后一次回调低点或关键支撑下方）
2. 预留一定缓冲，避免被正常波动扫出
3. 如果形态本身要求的止损空间过大，直接放弃该信号
4. 接近跌停时，优先考虑减仓，而不是幻想反弹

## 加仓规则

- 只在浮盈状态下加仓
- 用已有利润去承担新仓位的风险
- 绝不在亏损或成本附近加仓摊平

## 注意事项

- T+1导致当天买入无法卖出，因此止损必须提前规划，并接受可能出现的隔夜跳空
- 涨跌停会限制即时止损效率，仓位绝不能过大
