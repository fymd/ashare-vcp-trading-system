# 06 - 执行流程

## 每周固定动作

1. 扫描符合趋势模板的股票，更新观察池
2. 检查观察池中是否有临近VCP完成的标的
3. 复盘本周交易（如有）

## 每日固定动作

1. 检查大盘与主要板块环境
2. 浏览观察池，看是否出现进场信号
3. 对潜在信号使用「进场检查清单」逐条确认
4. 计算仓位与止损后再下单
5. 持仓股票检查关键均线与量价是否完好

## 每笔交易后

- 立即记录：进场理由、止损位置、仓位计算、当时市场环境
- 使用交易记录模板归档

## 每月复盘

统计以下数据：
- 总交易次数
- 胜率
- 平均盈利 / 平均亏损
- 盈亏比
- 最大回撤
- 最大单笔亏损

根据数据决定是否微调参数（例如风险比例、均线周期），但避免频繁大幅改动规则。

## 纪律工具建议

- 把「进场检查清单」打印或固定在交易界面旁边
- 使用交易日志强迫自己写下理由
- 设置账户最大日亏损或周亏损限制，触发后强制停止交易
