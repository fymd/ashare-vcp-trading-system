# 04 - 持仓与卖出

## 持有条件

同时满足以下条件才继续持有：

- 股价仍运行在关键均线（建议20日均线）上方
- 量价关系没有明显恶化（不是放量滞涨或缩量阴跌）
- 所属板块没有出现明显退潮迹象
- 大盘环境未转为明确下跌

## 卖出 / 减仓信号

出现以下任一情况，考虑减仓或清仓：

1. 跌破关键均线（20日或自定义）且无法在短时间内收回
2. 出现明显放量滞涨、长上影线或乌云盖顶等反转信号
3. 所属板块集体走弱、资金流出
4. 达到预设目标位（可分批止盈）
5. 出现重大负面催化或逻辑破坏

## 止盈方式建议

- **分批止盈**：到达第一目标位先减仓一部分，剩余仓位上移止损至成本或更高
- **移动止损**：随着股价上涨，将止损逐步上移至关键均线或前低下方
- **时间止盈**：持仓超过预期时间仍无进展，可考虑退出

## 特殊情况处理

- **涨停**：可继续持有，但次日打开后重新评估
- **跌停**：如果持仓较重，优先想办法降低风险（如对冲），而不是死扛
- **隔夜跳空**：开盘后根据实际情况决定是否执行原定止损

卖出纪律与进场纪律同等重要。很多亏损来自「该走的时候不走」。
