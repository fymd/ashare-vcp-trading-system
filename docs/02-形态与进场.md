# 02 - 形态与进场

## VCP 核心特征（必须满足）

在明确上升趋势中：

1. 出现 2~4 次回调（波浪）
2. 回调幅度逐步收窄（理想情况后一次约为前一次的一半左右）
3. 回调时成交量明显萎缩
4. 上攻时成交量放大

最终形成「波动收缩 → 卖压减轻」的状态。

## 进场方式（优先顺序）

### 方式一：回踩多重优势区（优先推荐）

股价回踩到以下因素重叠的区域后企稳：

- 旧阻力位变成支撑
- 10日或20日均线
- 其他水平关键位 / 趋势线

要求：回踩过程尽量缩量，企稳信号清晰。

### 方式二：放量突破收缩高点

- 突破前高（收缩形态的高点）
- 当日成交量 ≥ 前期收缩期平均成交量的 1.5~2 倍以上
- 最好伴随板块联动

## A股特别过滤规则（重要）

1. **不追高**：已经接近涨停或当日涨幅过大的票，宁可等待回踩。
2. **突破确认**：突破当天如果封板，次日打开后的表现需重新评估。
3. **板块共振**：同板块至少有 2~3 只股票同步走强，信号可靠性显著提升。
4. **大盘环境**：大盘或相关指数处于明显下降趋势时，提高进场门槛或空仓。

## 进场检查清单（下单前必须全部打勾）

- [ ] 符合趋势模板（50日 > 200日，均线向上）
- [ ] 存在清晰的VCP收缩特征
- [ ] 进场点属于多重优势区或放量突破
- [ ] 成交量配合良好
- [ ] 板块未明显退潮
- [ ] 已计算好仓位与止损
- [ ] 单笔风险在允许范围内
