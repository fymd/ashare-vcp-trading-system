# 05 - 常见失败与规避

| 失败类型 | 主要原因 | 规避方法 |
|----------|----------|----------|
| 假突破 | 无量突破、板块不配合、大盘环境差 | 强制要求放量 + 板块联动；大盘弱时提高门槛 |
| 买后直接大跌/跌停 | 追高、止损空间不足、隔夜风险 | 不追涨停附近；止损预留缓冲；控制单笔仓位 |
| 形态完美却失败 | 政策转向、板块退潮、突发利空 | 增加催化剂与板块环境过滤；接受一定失败率 |
| 频繁被止损 | 过滤条件过松、交易频率过高 | 提高选股与形态门槛，宁可少做 |
| 利润回吐严重 | 没有移动止损或过早止盈后追回 | 制定明确的分批止盈与移动止损规则 |
| 情绪化交易 | 连续止损后报复性交易，或大盈后过度自信 | 严格按清单执行；设置每日/每周最大亏损限制 |

## 额外建议

- 记录每一笔失败交易的原因，分类统计
- 连续亏损达到一定次数后强制休息
- 定期回顾「当时为什么进场」，检查是否严格执行了规则
