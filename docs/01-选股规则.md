# 01 - 选股规则

选股是整个系统的第一道过滤器，必须严格。

## 硬性条件（缺一不可）

1. **趋势模板**
   - 股价 > 50日均线
   - 50日均线 > 200日均线
   - 50日均线与200日均线均向上倾斜

2. **相对强度**
   - 近20个交易日涨幅明显跑赢沪深300或所属板块（建议进入板块/市场前30%）

3. **流动性**
   - 日均成交额 ≥ 3亿元（主板优先）
   - 创业板/科创板可适当放宽，但仍需保持较高活跃度，避免冲击成本过大

4. **趋势阶段**
   - 必须处于明确上升趋势（Stage 2）
   - 严禁在长期下跌趋势中的反弹形态上操作（下跌中继假VCP高发）

## 加分条件（越多信号质量越高）

- 有明确催化剂（业绩超预期、重要合同、政策支持、行业景气向上等）
- 所属板块处于市场主线或同步走强
- 北向资金、机构调研、融资余额等资金面有净流入迹象
- 股价距离阶段高点不远（优选强势股，而非超跌反弹）

## 明确排除

- ST、*ST 股票
- 流动性极差、买卖价差巨大的标的
- 近期有重大负面公告或大比例减持
- 纯概念炒作且无基本面支撑的题材股（除非你有非常明确的短线规则）

## 选股建议工具

- 通达信 / 同花顺 / 东方财富 自定义选股公式
- 重点扫描：均线多头排列 + 近期相对强度强 + 成交额达标

选股池建议控制在可管理数量（例如20-50只），每周更新一次。
