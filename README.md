# A股优化版 VCP + 多重优势交易系统

> 基于 J Law / Mark Minervini VCP（波动收缩形态）策略，针对A股市场特点（涨跌停、T+1、散户主导、政策市）进行优化后的实战交易系统。

**重要声明**：本系统仅供学习与研究使用，不构成任何投资建议。股市有风险，投资需谨慎。过往表现不代表未来收益。使用者需自行承担所有交易风险。

## 系统简介

本系统核心逻辑：
- **顺势交易**：只做明确上升趋势中的股票
- **等待卖压消化**：通过VCP形态捕捉波动收缩后的低风险高盈亏比机会
- **多重优势确认**：要求多个支撑/理由在同一价格区域重叠才进场
- **严格风险控制**：单笔风险严格限制，适应A股T+1与涨跌停特性

## 快速开始

1. 阅读 `docs/` 下的全部规则文档
2. 使用 `templates/每日检查清单.md` 进行日常扫描
3. 用小资金或模拟盘完整跑通至少2-3个月
4. 根据自己的交易记录持续优化参数（但不要频繁改规则）

## 核心原则

1. **宁缺母滥**：过滤条件严格，交易频率低于美股原版
2. **风险优先**：仓位与止损规则不可妥协
3. **适应市场**：只在趋势明确时积极操作，震荡/下跌市大幅降低仓位
4. **持续复盘**：每月统计胜率、盈亏比、最大回撤
